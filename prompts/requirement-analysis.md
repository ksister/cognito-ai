# 需求分析

读取 `customers/*/records/*.md` 中 frontmatter 的 `needs` 字段和「我的思考」，以及 `01-me/goals.md`：

1. 把相似痛点聚类成需求，每个需求列出：痛点、涉及客户与次数、原话证据（引用记录文件路径）、建议方案、价值、优先级（P0/P1/P2）。
2. 单独列出「AE 自己就能先做的辅助工具」（脚本、小程序、模板、文档）。
3. 指出哪些需求证据不足、需要再找哪类客户验证。
4. 保存到 `requirements/YYYY-MM-DD-需求分析.md`。

也可以在工作台「需求池」页面点「生成需求分析」自动完成第 1 步。
