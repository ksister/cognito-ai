# 每周回顾

读取过去 7 天的 `journal/`、所有活跃项目的 `log.md` 和 `01-me/goals.md`：

1. 按 `templates/weekly-review.md` 生成本周回顾，保存到 `03-areas/reviews/YYYY-Www.md`。
2. 指出：我的时间花费和季度目标是否一致？哪些事情在反复出现却没被解决？
3. 找出可以沉淀为模板 / 提示词 / 方法论的重复工作，建议放入 `04-resources/`。
4. 列出你认为应该更新到 `01-me/` 的内容（先列出，等我确认）。
5. 检查 `00-inbox/` 是否有超过 7 天未整理的文件。
